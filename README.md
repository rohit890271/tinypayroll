# TinyPayroll

## About
TinyPayroll is a modern, lightweight payroll management solution designed for small businesses and startups. The goal is to simplify employee onboarding, dashboard analytics, and salary distributions using seamless integrations with Stripe for payments and Supabase for secure data management.

This project was built leveraging the power of AI-assisted development ("vibe coding"), using tools like Codex and other AI apps to quickly iterate, build UI components, and connect complex integrations.

## Tech Stack
- Next.js
- React
- Supabase
- Stripe
- Tailwind CSS
- TypeScript
